# Alex Chen — Academic Homepage Template

一个面向 AI / CS 博士生的单页学术主页模板。纯 HTML + CSS + JavaScript，无构建步骤，直接部署到 GitHub Pages、Netlify 或学校服务器即可。

## 快速开始

直接打开 `index.html` 预览。替换以下内容即可完成个人定制：

- `index.html`：姓名、学校、研究方向、论文、新闻、联系方式和社交链接
- `styles.css`：颜色、间距、字体和响应式布局
- `assets/alex-chen-cv.pdf`：放入自己的 CV（当前链接是占位路径）

页面采用暖白背景、深墨蓝文字和珊瑚橙强调色，研究方向用三张“研究卡片”呈现，论文缩略图暂时使用 CSS 几何图形，后续可以替换成论文 teaser image。
